# 3D 포즈 블로킹 도구 계획서

> 상태 (2026-10-02). 1차 버전(MVP)에 이어 2차 개선(카메라 위치 이동과 방향 제어, 자세 프리셋 12종, 좌우 패널 분리, 마주보기, 소품 10종, 링크와 파일 공유)까지 구현하고 자동 검증을 마쳤습니다. 배포용 프로젝트는 `index.html`, `css/style.css`, `js/app.js`로 나뉜 정적 사이트이고, 확인용 단일 파일은 빌드 스크립트로 따로 만듭니다. 배포 전에 `og-image.png` 추가가 필요합니다.

## 1. 무엇을 만드는가

AI 영상 제작용 레퍼런스 이미지를 만드는 **3D 포즈 블로킹 도구**입니다. 졸라맨 형태의 3D 캐릭터를 배치하고 포즈를 잡은 뒤, 카메라 앵글과 구도를 정해서 PNG 또는 클립보드로 바로 내보냅니다.

## 2. 왜 만드는가

- 영상 AI에서 화면 구성을 프롬프트로 설명하기 어렵습니다.
- 지금은 2D 스케치를 레퍼런스로 쓰는데, 카메라 각도와 구도를 나중에 다시 조정해야 합니다.
- 3D로 한 번에 잡으면 인물 배치, 높이 차이, 카메라 앵글이 레퍼런스 한 장에 모두 담깁니다.

## 3. 핵심 사용 흐름

1. 도구를 엽니다. 기본 캐릭터 1명이 서 있습니다.
2. 관절 구를 잡아 끌어 포즈를 만듭니다.
3. 관절을 클릭해서 회전 링으로 각도를 다듬습니다.
4. 캐릭터를 추가하고 위치와 키를 조절합니다.
5. 카메라 앵글, 화각, 화면비를 정합니다.
6. 캡처 버튼을 누르면 화면이 깜박이고 메인 화면만 클립보드에 복사됩니다.
7. 영상 AI 도구에 붙여넣거나 PNG로 저장합니다.

## 4. 1차 버전 범위 (MVP)

- 3D 뷰포트 (그리드 바닥, 궤도 카메라)
- 24개 관절 골격을 가진 졸라맨 캐릭터
- 손목·발목 IK 드래그, 나머지 관절 FK 회전 링
- 캐릭터 추가·삭제, 캐릭터별 색상, 머리 위 이름 라벨
- 캐릭터 이동, 회전, 키 조절
- 출력 카메라 (화면비 프리셋, 화각 슬라이더, 높이 프리셋, 프레임 밖 어둡게)
- PNG 내보내기, 클립보드 캡처 (깜박임 효과, 기즈모와 그리드 자동 숨김)
- 되돌리기와 다시 실행
- 포즈 저장과 불러오기 (포즈 단위, 씬 단위, 썸네일 목록, JSON 내보내기와 가져오기)

## 5. 2차 버전 이후

- 좌우 대칭 토글
- 실루엣과 뎁스맵 내보내기

## 5-0. 2차 개선 내용 (반영 완료)

- **자세 프리셋 12종.** 기본 서기, 편하게 서기, 걷기, 달리기, 앉기, 쪼그려 앉기, 손 흔들기, 악수, 가리키기, 팔짱, 손 들기, 점프. 적용하면 발이 바닥에 자동으로 맞춰집니다.
- **카메라 위치 이동.** 슬라이더, 작업 뷰에서 카메라 직접 드래그, W A S D Q E 키, "출력 카메라 찾기" 버튼.
- **마주보기와 방향 맞추기.** 바닥 화살표가 발 방향을 가리키고, 끌어서 전체를 회전합니다. 상대 바라보기, 서로 마주보기, 하체를 상체에 맞추기 버튼이 있습니다.
- **소품 10종.** 박스, 의자, 테이블, 소파, 침대, 계단, 벽, 기둥, 공, 자동차. 이동, 크기, 색, 방향, 띄우기, 복제, 삭제를 지원하고 되돌리기와 씬 저장에 포함됩니다.
- **공유와 내보내기.** 포즈와 씬을 링크(서버 없이 주소에 압축해 담음)나 파일로 공유합니다. 받는 사람이 링크를 열면 자동으로 불러오고, 씬은 확인 후 열며 기존 작업은 자동 보관됩니다.
- **카메라 방향 제어.** 좌우, 상하, 기울기 슬라이더, 두 가지 드래그 회전 방식(제자리 회전, 선택 캐릭터 중심 회전. 3D 화면 오른쪽 위에서 전환, Alt는 반대, R 키), 방향키, 작업 뷰 조준점, 선택 캐릭터 바라보기.
- **패널 분리.** 왼쪽은 설정(캐릭터, 소품, 카메라, 보기), 오른쪽은 라이브러리(프리셋, 내 포즈, 씬). 모두 탭 구성이라 스크롤이 길어지지 않습니다.

## 5-1. 포즈 저장 설계

- **포즈**는 캐릭터 1명의 관절 회전값만 저장합니다. 위치와 키는 제외하므로 어떤 캐릭터에도 적용할 수 있습니다.
- **씬**은 모든 캐릭터의 포즈와 위치, 카메라 설정, 화면비를 통째로 저장합니다.
- 저장 시 현재 화면의 썸네일을 함께 만들어 목록에서 그림으로 고르게 합니다.
- 저장소는 localStorage이며, 백업용으로 JSON 내보내기와 가져오기를 제공합니다.
- 이름 변경과 삭제를 지원합니다.
- localStorage는 Claude 미리보기에서는 막혀 있으므로, 완성본은 파일로 받아 브라우저에서 직접 여는 방식을 기본으로 합니다.

## 6. 24개 관절 구성

| 부위 | 관절 | 개수 |
|---|---|---|
| 몸통과 머리 | 머리, 목, 상부 척추, 중부 척추, 하부 척추, 골반(루트) | 6 |
| 팔 | 좌우 쇄골, 어깨, 팔꿈치, 손목 | 8 |
| 손 | 좌우 손끝 | 2 |
| 다리 | 좌우 엉덩이, 무릎, 발목, 발끝 | 8 |
| 합계 | | 24 |

- 골반이 루트 관절이며 캐릭터 전체 이동의 기준이 됩니다.
- 손목과 발목은 IK 타깃으로 쓰고, 그 외 관절은 회전 링으로 조작합니다.

## 7. 기술 방향

- 렌더링은 Three.js를 씁니다.
- 빌드 없는 정적 사이트(`index.html` + `css/style.css` + `js/app.js`)로 만들어 설치 없이 열고 Vercel에 그대로 배포합니다. 확인용 단일 HTML은 `node scripts/build-single.mjs`로 생성합니다.
- IK는 2본 해석적 IK(어깨-팔꿈치-손목, 엉덩이-무릎-발목)로 구현합니다. 가볍고 안정적입니다.
- 회전 컨트롤은 빨강·초록·파랑 3개 링으로 구성합니다.
- 클립보드는 Clipboard API로 복사하고, 실패하면 PNG 다운로드로 대체합니다.
- 캡처는 렌더러 캔버스만 읽어서 UI 요소가 섞이지 않게 합니다.

## 8. 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| 클립보드 이미지 복사는 HTTPS 또는 localhost에서만 동작합니다 | 실패 시 PNG 다운로드로 자동 전환하고 안내 문구를 보여 줍니다 |
| 관절 드래그와 카메라 회전이 충돌합니다 | 관절 위에서는 카메라 회전을 잠그고, 빈 공간에서만 카메라를 돌립니다 |
| 뼈 길이가 늘어납니다 | 모든 이동을 회전 기반으로 계산해 뼈 길이를 고정합니다 |
| 조작이 복잡해집니다 | 선택 상태에 따라 보이는 핸들을 달리해 한 번에 한 가지만 다루게 합니다 |

## 9. 성공 기준

- 처음 쓰는 사람이 설명 없이 3분 안에 2인 구도를 만들 수 있습니다.
- 캡처한 이미지에 UI 요소가 하나도 섞여 있지 않습니다.
- 팔다리를 아무리 끌어도 뼈 길이가 변하지 않습니다.
- 캡처 후 영상 AI 입력창에 바로 붙여넣을 수 있습니다.
