# PoseBlock 3D v1.7.0 Context Notes

## 기준 버전
- 기준: v1.6.9
- 목표: v1.7.0

## 이번 작업 범위
1. 기존 오른쪽 패널의 12개 프리셋은 `기본 프리셋`으로 그대로 유지한다.
2. 헤더의 캡처 왼쪽 중복 `공유` 버튼을 제거하고 `프리셋 사전` 버튼으로 교체한다.
3. 프리셋 사전은 별도 URL 이동이 아니라 같은 앱 안의 내부 화면으로 구현한다. 현재 씬과 WebGL 상태는 유지한다.
4. 사전 상단에 검색, 인원 필터(전체/1인/2인), 다중 태그 필터를 둔다.
5. 초기 사전은 1인 12개 + 2인 12개 = 24개로 구성한다.
6. 1인 프리셋은 현재 선택 캐릭터에 즉시 적용한다.
7. 2인 프리셋은 카드 클릭 후 A/B 캐릭터를 사용자가 직접 선택하고 적용한다.
8. 캐릭터가 1명뿐이면 2인 적용을 위해 두 번째 캐릭터를 자동 추가한 뒤 선택 창을 연다.
9. 2인 프리셋은 동일 키 175cm 기준이며, 포즈 + 상대 위치 + 방향을 함께 적용한다.
10. 적용 후 기존 관절/위치 수정 기능은 그대로 사용할 수 있어야 한다.

## 비범위
- 기본 12개 프리셋의 내용/위치/동작 변경 금지
- 기존 캐릭터/에셋/카메라/저장/캡처/조작 규칙 변경 금지
- 기존 공유 기능 전체 삭제 금지 (`저장 없이 공유`, 저장 항목의 공유/내보내기는 유지)
- 외부 페이지 이동 방식 사용 금지

## 확장 원칙
- 프리셋 데이터는 UI와 분리된 구조로 유지한다.
- `people`, `tags`, `roles`, `pose`, `layout` 필드를 사용해 향후 3인+, 격투, 스포츠, 로맨스 등으로 확장 가능하게 한다.
- 하나의 프리셋에 여러 태그를 허용한다.
