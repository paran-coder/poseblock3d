# PoseBlock 3D v1.5.0 Context Notes

## 기준 버전
- 기준: poseblock3d-v1.4.0
- 새 버전: poseblock3d-v1.5.0

## 이번 요청 범위
1. 화면 이동 조작을 `Space + 좌클릭 드래그`로 사용할 수 있게 한다.
2. 화면 안내 문구에서 우클릭 이동보다 `Space + 드래그`를 기본 안내로 표시한다.
3. 첨부 화면에서 `캐릭터 추가 / 선택 삭제` 버튼 행과 `이름` 입력 행이 붙어 보이는 간격을 수정한다.
4. 그 외 캐릭터/관절/에셋/카메라/저장/캡처/공유 로직은 변경하지 않는다.

## 구현 원칙
- `Space`를 누른 상태에서 좌클릭 드래그하면 화면 pan을 시작한다.
- Space pan이 활성화된 동안에는 관절/캐릭터/에셋 선택이나 드래그보다 pan이 우선한다.
- 입력창/텍스트영역/셀렉트에 포커스가 있을 때는 Space를 가로채지 않는다.
- 기존 우클릭/중클릭 pan은 호환성을 위해 유지하고, 새 조작을 기본 안내로 표시한다.
- 캐릭터 패널 간격 수정은 전역 `.row` 규칙을 바꾸지 않고 `#charCtl` 시작 간격만 조정한다.

## 확인 포인트
- Space + 좌클릭 드래그로 작업 뷰와 카메라 뷰 모두 pan 되는가.
- Space를 누르지 않은 기존 좌클릭 드래그 동작은 그대로인가.
- 입력 필드에서 Space 입력이 방해받지 않는가.
- 캐릭터 추가/삭제 버튼과 이름 입력칸 사이가 시각적으로 분리되는가.


## 구현 결과
- `Space` 키를 누른 상태에서 장면을 좌클릭 드래그하면 `activeRig().pan(...)`을 사용해 작업 뷰와 카메라 뷰를 동일하게 이동한다.
- Space pan은 장면의 관절/캐릭터/에셋 hit-test보다 먼저 처리해 선택/변형과 충돌하지 않는다.
- Space를 누르는 동안 `grab`, 실제 드래그 중 `grabbing` 커서를 표시한다.
- 텍스트 입력, 셀렉트, 버튼, 링크, contenteditable 요소에서는 Space pan을 시작하지 않는다.
- 기존 우클릭/중클릭 pan과 빈 곳 Shift+드래그 pan은 호환성을 위해 유지했다.
- 캐릭터 패널의 `#charCtl`에만 `margin-top: 8px`을 추가해 버튼 행과 이름 입력 행을 분리했다.
- 헤더 버전과 CSS/JS 캐시 버전을 `v1.5.0`으로 갱신했다.

## 검증
- `node --check js/app.js` 통과.
- `node --check scripts/build-single.mjs` 통과.
- `node scripts/build-single.mjs`로 단일 HTML 재생성, 정적 WebP 썸네일 24개 내장 확인.
- v1.4.0 대비 핵심 변경은 화면 pan 입력 처리, HUD/도움말 문구, `#charCtl` 간격, 버전 문자열에 한정됨.
