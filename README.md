# PoseBlock 3D v1.4.0

**https://poseblock3d.vercel.app/**

AI 영상 제작용 **3D 포즈 블로킹 도구**입니다. 졸라맨 캐릭터와 에셋을 3D로 배치하고, 카메라 앵글과 구도를 잡은 뒤 클릭 한 번으로 레퍼런스 이미지를 만듭니다. 프롬프트로 설명하기 어려운 인물 배치와 카메라 구도를 이미지 한 장으로 전달하세요.

정적 사이트라 별도 설치나 빌드 없이 `index.html`을 열면 바로 동작합니다.

## 주요 기능

| 구분 | 내용 |
|---|---|
| 캐릭터 | 24개 관절 졸라맨 최대 5명. 손목·발목은 IK, 나머지는 끌어서 휘두르거나 회전 링으로 정밀 조절. 키, 방향, 색, 이름 설정 |
| 자세 프리셋 | 기본 서기, 걷기, 달리기, 앉기, 쪼그려 앉기, 손 흔들기, 악수, 가리키기, 팔짱, 손 들기, 점프 등 12종. 적용하면 발이 바닥에 자동으로 맞춰짐 |
| 마주보기 | 상대 바라보기, 서로 마주보기, 하체를 상체 방향에 맞추기. 바닥 화살표를 끌어 전체 회전 |
| 에셋 | 박스, 의자, 테이블, 소파, 침대, 계단, 벽, 기둥, 공, 자동차, 개, 고양이, 말, 새, 호랑이, 용, 거북이, 구렁이, 자전거, 오토바이, 버스, 트럭, 보트, 비행기. 이동, 크기, 색, 방향, 띄우기, 복제 |
| 출력 카메라 | 화면비 5종, 화각, 앵글 프리셋, 위치와 방향(좌우, 상하, 기울기) 조절. 작업 뷰에서 주황색 카메라를 직접 끌어 이동 |
| 캡처 | 클립보드 복사(깜박임 효과), PNG 저장. 조작 도구는 이미지에 섞이지 않음 |
| 저장과 공유 | 포즈와 씬 저장, 링크와 파일 공유, 되돌리기와 다시 실행, 자동 저장 |



## v1.3.0 변경 사항

- 동물 카테고리의 호랑이, 용, 거북이 목록 표시를 안정화합니다.
- 페이지 새로고침 시 현재 작업 씬을 자동 복원하지 않고 기본 씬으로 시작합니다.
- 헤더 로고를 홈페이지 링크로 만들고 `v1.3.0` 버전을 표시합니다.
- 명시적으로 저장한 내 포즈/씬과 JSON 형식은 유지합니다.

## v1.2.0 변경 사항

- 개와 고양이의 몸통 비례, 귀, 주둥이, 꼬리 실루엣을 구분했습니다.
- 버스는 일체형 승객실과 반복 창문, 트럭은 분리된 운전석과 열린 적재함으로 형태를 구분했습니다.
- 동물 에셋에 호랑이, 동양식 용, 거북이를 추가해 총 23종으로 확장했습니다.
- 에셋 추가 목록을 `기본 / 동물 / 탈것`으로 분류하고 기존 4열 카드 그리드를 유지했습니다.
- 저장 데이터의 `props` 구조와 기존 타입 키, 에셋 조작 로직은 변경하지 않아 기존 씬 호환성을 유지합니다.

## v1.1.0 변경 사항

- UI 표시 용어를 `소품`에서 `에셋`으로 통일했습니다.
- 기존 10종은 그대로 유지하고 개, 고양이, 말, 새, 자전거, 오토바이, 버스, 트럭, 보트, 비행기를 추가해 총 20종으로 확장했습니다.
- 내부 저장 형식과 기존 에셋 조작 로직은 유지하여 이전 씬과 호환됩니다.

## 사용 흐름

1. 관절 구를 끌어 포즈를 만들고, 필요하면 색 링으로 각도를 다듬습니다. 오른쪽 프리셋을 눌러 시작해도 됩니다.
2. 캐릭터와 에셋을 추가하고 위치를 정합니다.
3. `Tab`으로 카메라 뷰로 바꿔 구도를 잡습니다.
4. `C`로 클립보드에 복사한 뒤 영상 AI 도구에 붙여넣거나, `P`로 PNG를 저장합니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Tab` | 작업 뷰와 카메라 뷰 전환 |
| `C` / `P` | 클립보드 캡처 / PNG 저장 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시 실행 |
| `R` | 드래그 회전 방식 전환 (제자리 / 대상 중심). `Alt`를 누르는 동안은 반대 |
| `Shift`+끌기 | 캐릭터나 에셋, 카메라를 위아래로 이동 |
| `Delete` | 선택한 에셋 삭제 |
| `W A S D` `Q E` | 카메라 뷰에서 카메라 이동, 아래위 |
| 방향키, `Z` `X` | 카메라 뷰에서 카메라 회전, 기울기 |
| `Esc` | 선택 해제, 공유 창 닫기 |

## 공유하는 방법

- **링크.** 헤더의 `공유` 버튼이나 라이브러리 카드의 `공유 · 내보내기`로 링크를 만듭니다. 서버 없이 링크 주소에 데이터를 압축해 담습니다. 받는 사람이 열면 포즈는 `내 포즈`에 추가되고, 씬은 확인 후 열립니다.
- **파일.** 같은 창에서 `파일로 저장`을 누르면 JSON 파일이 만들어집니다. 받는 사람은 `JSON 가져오기`로 불러옵니다.
- 링크는 **웹에 배포된 주소에서 만든 것**만 다른 사람이 열 수 있습니다. 내 컴퓨터의 파일로 연 상태에서 만든 링크는 그 컴퓨터에서만 열리니, 이때는 파일로 공유하세요.

## 프로젝트 구조

```
index.html                화면 뼈대, 메타 태그, OG 태그
css/style.css             전체 스타일
js/app.js                 앱 로직 (장면, 캐릭터, 에셋, 카메라, 캡처, 저장, 공유)

docs/                     계획서, 체크리스트, 설계 기록
```

## 확인용 단일 파일 만들기

파일 하나로 열어서 확인하거나 전달하고 싶을 때 사용합니다. Node.js 18 이상이면 되고 패키지 설치는 필요 없습니다.

```bash
node scripts/build-single.mjs
# dist/poseblock-single.html 이 만들어집니다 (저장소에는 올라가지 않습니다)
```

## 로컬에서 실행하기

`index.html`을 브라우저로 열면 바로 동작합니다. 다만 **클립보드 복사는 HTTPS 또는 localhost에서만** 동작하므로, 클립보드 캡처까지 쓰려면 간단한 서버로 여세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 을 엽니다
```

Three.js를 CDN(cdnjs)에서 불러오므로 인터넷 연결이 필요합니다.

## Vercel에 배포하기

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Vercel에서 `Add New → Project`로 저장소를 가져옵니다.
3. Framework Preset은 `Other`, Build Command와 Output Directory는 비워 둡니다. 정적 파일이라 빌드가 필요 없고, 저장소 최상위가 그대로 배포됩니다.
4. `Deploy`를 누릅니다.

## OG 이미지 설정

링크를 공유할 때 보이는 미리보기 이미지입니다. `index.html`에는 태그가 미리 들어 있고, 이미지 파일은 직접 추가해야 합니다.

1. 가로 1200px, 세로 630px의 이미지를 `og-image.png`로 저장해 `index.html`과 같은 폴더에 둡니다.
2. `index.html`의 OG 태그는 이미 배포 주소(`https://poseblock3d.vercel.app/`)의 절대 주소로 설정되어 있습니다. 많은 SNS 크롤러가 상대 경로를 읽지 못하기 때문입니다. 도메인을 바꾸면 `canonical`, `og:url`, `og:image`, `twitter:image` 네 곳의 주소를 함께 바꾸세요.
3. 파일을 올린 뒤 이미지 주소(`https://poseblock3d.vercel.app/og-image.png`)가 브라우저에서 열리는지 확인합니다. SNS는 미리보기를 캐시하므로, 이전에 공유한 적이 있다면 [Facebook 공유 디버거](https://developers.facebook.com/tools/debug/)나 각 서비스의 도구로 캐시를 새로 고쳐야 합니다.

## 기술 스택

- 순수 HTML, CSS, JavaScript (빌드 도구 없음)
- [Three.js](https://threejs.org/) r128 (cdnjs)
- 저장은 브라우저 `localStorage`를 사용합니다. 브라우저 데이터를 지우면 사라지니, 중요한 자료는 `JSON 내보내기`로 백업하세요.
