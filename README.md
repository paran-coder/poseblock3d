# PoseBlock 3D v1.7.0

PoseBlock 3D는 브라우저에서 캐릭터 포즈, 다인 장면, 에셋과 카메라 구도를 빠르게 블로킹하는 3D 포즈 도구입니다.

## v1.7.0 핵심 변경

- 오른쪽 패널의 기존 12개 프리셋은 `기본 프리셋`으로 그대로 유지합니다.
- 헤더의 중복 `공유` 버튼 자리에 `프리셋 사전` 버튼을 추가했습니다.
- 프리셋 사전은 현재 씬을 유지한 채 열리는 앱 내부 화면입니다.
- 이름/태그 검색, `전체 / 1인 / 2인` 필터, 다중 태그 필터를 제공합니다.
- 초기 사전 콘텐츠는 1인 12개 + 2인 12개, 총 24개입니다.
- 1인 프리셋은 현재 선택 캐릭터에 즉시 적용됩니다.
- 2인 프리셋은 A/B 역할 캐릭터를 사용자가 직접 지정한 뒤 적용합니다.
- 캐릭터가 1명뿐이면 두 번째 캐릭터를 자동 추가합니다.
- 2인 프리셋은 175cm 동일 키 기준이며 자세, 상대 위치, 방향을 함께 적용합니다.
- 적용 후에는 기존 관절 및 위치 조작으로 자유롭게 미세 조정할 수 있습니다.

## 프리셋 사전 확장 구조

각 사전 프리셋은 인원 수, 이름, 다중 태그, 포즈 데이터와 배치 데이터를 분리해 관리합니다. 이 구조를 유지하면 이후 `3인+`, `격투`, `스포츠`, `로맨스`, `연출` 등의 카테고리를 기존 UI를 뜯지 않고 추가할 수 있습니다.

기존 캐릭터, 에셋, 카메라, 저장/불러오기, 캡처, 공유 기능은 유지합니다.
