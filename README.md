# PoseBlock 3D v2.1.4

PoseBlock 3D는 브라우저에서 캐릭터 포즈, 다인 장면, 에셋과 카메라 구도를 빠르게 블로킹하는 3D 포즈 도구입니다.


## v1.9.0 핵심 변경

- 에셋 방향 편집을 `좌우 방향`과 `상하 방향`으로 확장합니다.
- Shift+클릭으로 여러 에셋을 선택하거나 선택 해제할 수 있습니다.
- 여러 에셋을 선택한 상태에서 일반 드래그는 함께 평면 이동, Shift+드래그는 함께 위/아래 이동합니다.
- 다중 선택에서는 이동과 삭제만 지원하며 색상·크기·회전·복제는 단일 선택에서만 사용합니다.
- 기존 씬의 에셋은 `pitch=0`으로 호환되어 이전 저장 데이터가 그대로 열립니다.

## v1.8.1 수정

- `벽치기`에서 벽을 짚는 B의 손이 A 어깨를 관통하지 않도록 벽 쪽 팔 위치를 보정했습니다.
- 프리셋이 자동 생성한 벽은 다른 2인 프리셋으로 전환할 때 제거되며, 사용자가 직접 추가한 에셋은 유지합니다.
- 따라서 `키스` 프리셋에는 벽이 따라오지 않습니다.

## v1.8.0 핵심 변경

- 프리셋 사전에 2인 액션 프리셋 `이단옆차기`를 추가했습니다.
- `이단옆차기`는 사용자가 제작한 공유 씬의 175cm/175cm 관절·상대 배치 데이터를 그대로 사용합니다.
- 프리셋 사전에 `벽치기`를 추가했습니다.
- `벽치기`는 175cm/175cm 기준으로 정규화하고, 벽을 짚는 손은 유지하면서 상대 얼굴에 닿는 손만 미세 보정했습니다.
- `벽치기`를 적용하면 포즈와 함께 벽 에셋도 자동으로 추가됩니다.
- 기존 `키스` 프리셋은 사용자가 제작한 `키스신` 씬의 관절·상대 배치 데이터로 교체했습니다.
- 기존 `안아들기`와 나머지 프리셋 및 조작 기능은 그대로 유지합니다.

## 프리셋 사전

프리셋 사전은 현재 씬을 유지한 채 열리는 앱 내부 화면입니다. 이름/태그 검색, `전체 / 1인 / 2인` 필터와 다중 태그 필터를 제공합니다.

현재 사전은 1인 12개 + 2인 14개, 총 26개 프리셋으로 구성됩니다. 2인 프리셋은 A/B 역할 캐릭터를 사용자가 직접 지정합니다.

## 씬형 프리셋

일반 2인 프리셋은 두 캐릭터의 포즈와 상대 배치만 적용합니다. `벽치기`처럼 장면 에셋이 필수인 프리셋은 필요한 에셋도 함께 추가할 수 있습니다. 기존 씬의 다른 에셋은 삭제하지 않습니다.

## v2.0.0 · 이미지에서 포즈 만들기

헤더의 `이미지 포즈`에서 사람 1명이 나온 정지 이미지를 불러오면 브라우저에서 관절을 분석하고 이미지 위에 스켈레톤을 표시합니다. 잘못 잡힌 주요 관절점은 직접 드래그해 수정한 뒤 `이 포즈 적용`을 눌러 현재 선택 캐릭터에 초기 3D 포즈로 반영할 수 있습니다.

분석은 MediaPipe Pose Landmarker를 사용합니다. 이미지 입력은 기기 안에서 처리되며 이미지 자체를 PoseBlock 서버나 별도 AI API에 업로드하지 않습니다. 최초 사용 시 MediaPipe 런타임과 포즈 모델 파일을 인터넷에서 내려받아야 합니다. 정지 이미지 한 장의 깊이 추정에는 한계가 있으므로 적용 결과는 자동 완성본이 아니라 3D 편집을 시작하기 위한 초기 포즈로 사용합니다.




## v2.1.4 · A/B 인물 분리 고정

- 2인 분석은 Object Detector의 `person` 영역을 **우선** 사용하고, 화면 왼쪽 영역을 A, 오른쪽 영역을 B로 고정합니다.
- 각 영역은 좁은 crop부터 단계적으로 넓혀 가며 `numPoses=1`로 독립 분석합니다.
- 정밀 분석 결과의 어깨·골반 중심이 배정된 사람 영역을 벗어나면 해당 결과를 폐기합니다.
- A와 B의 신체 중심과 주요 관절이 지나치게 겹치면 같은 사람을 두 번 잡은 것으로 판정해 B 결과를 표시하지 않습니다.
- Object Detector가 사람 2명을 분리하지 못할 때만 전체 이미지 `numPoses=2`를 **ROI 공급용 fallback**으로 사용하며, fallback 포즈를 그대로 최종 결과로 쓰지 않습니다.
- 한쪽 인물 분석에 실패하면 다른 사람의 잘못된 스켈레톤을 대신 표시하지 않고 `A/B 인물을 찾지 못했습니다` 상태로 남깁니다.
- 반복 분석 안정화를 위한 v2.1.3의 전용 CPU 분석기와 run token은 그대로 유지합니다.
- v2.0.1의 1인 이미지 처리와 그 밖의 기존 기능은 변경하지 않습니다.

## v2.1.3 · 2인 이미지 인식 개선

- v2.0.1의 1인 이미지 분석/관절 드래그/3D 적용 JS 블록을 그대로 유지합니다.
- 1인/2인 전환은 화면 왼쪽 위의 독립 버튼이 아니라 이미지 카드 안의 `1인 이미지 / 2인 이미지` 탭으로 이동했습니다.
- 2인 이미지는 먼저 Object Detector로 사람 2명의 영역을 찾은 뒤, 각 사람 영역을 잘라 기존 1인 Pose Landmarker(`numPoses=1`)로 A/B를 따로 분석합니다.
- 사람 크롭은 여러 여백 후보를 비교해 대상 사람 중심에 가장 잘 맞는 포즈를 선택하며, 크롭 좌표는 다시 원본 이미지 좌표로 환산합니다.
- 사람 영역 분리가 실패할 때만 기존 전체 이미지 `numPoses=2` 분석을 fallback으로 사용합니다.
- 3D 변환 역시 별도 2인 수식을 유지하지 않고 v2.0.1의 `applyImagePoseToChar()`를 A/B에 각각 재사용합니다.
- 두 캐릭터의 초기 X 간격은 원본 이미지의 골반 중심과 감지된 사람 높이를 기준으로 계산하고, 화면의 발 높이 차이는 보수적인 Z 힌트로만 사용합니다.
- 프리셋, 에셋, 캐릭터 조작, 카메라, 저장/공유 등 이미지 포즈 외 기능은 변경하지 않습니다.


## v2.1.3
2인 이미지 분석을 기존 1인 분석기와 완전히 분리했습니다. 먼저 전체 이미지에서 두 사람의 포즈 후보를 찾은 뒤 각 사람을 별도로 다시 분석합니다. 연속 분석 시 이전 실행이 새 이미지에 섞이지 않도록 실행 토큰을 추가했고, 2인 전용 분석은 CPU delegate로 실행해 반복 분석 안정성을 높였습니다.
